## 🎯 My Recommendation — Minimal Killer Free Product

**Strategy**: Beat paid products by doing what they CAN'T (voice, auto-screenshots, local AI, privacy). Not by cloning 600 features badly.

### Why This Beats TradesViz (Paid) & Every Other Journal

| Feature | TradesViz | Our Free Product |
|---------|-----------|-----------------|
| Price | $10–16/mo | **Free forever** |
| Voice journal entry | ❌ None | ✅ Hotkey → speak → Whisper transcribes |
| Auto screenshot on entry/exit | ❌ None | ✅ Auto-capture via hotkey/broker event |
| Data privacy | Cloud (their servers) | **Local only** — your machine |
| AI features | Paid OpenAI API | **Local Ollama** — free, private |
| Broker auto-sync | Paid only | Free (file-based + MT4/5 bridge) |
| Stats | 600+ (overwhelming) | **20-30 actionable ones** |
| Setup time | Account + config + import | **Download → run** |

### The Minimal Feature Set (V1)

#### Core Journal (5-10 min to learn)
- [ ] Quick trade entry form — instrument, direction, size, entry/exit price, date/time, P&L auto-calculated
- [ ] Trade log — sortable, filterable list with inline edit, color-coded green/red
- [ ] Per-trade journal notes — text + voice (dictate via hotkey → Whisper transcribes)
- [ ] Dashboard — today's P&L, open positions, win rate, equity curve

#### Screenshots (killer feature — nobody does this)
- [ ] **Auto-capture on trade events** — triggered by broker connector or manual action:
  - On **entry** — capture immediately when trade opens
  - On **add/scale-in** — capture when position increases
  - On **stop loss move** — capture when SL is adjusted
  - On **close/exit** — capture when trade closes
  - On **any modification** — capture on TP adjust, breakeven move, etc.
- [ ] **Manual hotkey capture** — press a key anytime, screenshot attached to current trade
- [ ] Screenshot gallery per trade — click to expand, thumbnail grid, chronological timeline
- [ ] One-click replay — entry → mid → exit screenshots as filmstrip/flipbook

#### Statistics (20-30 that actually matter)
- [ ] Win rate, Profit Factor, R-Value (average), Expectancy
- [ ] Avg Win, Avg Loss, Win/Loss Ratio
- [ ] Max Drawdown (account), Max Consecutive Losses
- [ ] Sharpe Ratio (simplified)
- [ ] Equity curve chart
- [ ] P&L by instrument, by month
- [ ] Trade duration analysis
- [ ] Best/worst trades
- [ ] Strategy tag filtering — compare performance by strategy tag

#### Broker Sync (the killer free feature)
- [ ] **Historical CSV import** — import past trades from any broker so stats work immediately on your trading history (not just new trades). Accept standard CSV format with mapping tool.
- [ ] MT4/MT5 auto-sync — watch file export folder, auto-import new trades (covers FTMO, Top Step)
- [ ] NT8 TradePerformance auto-import
- [ ] Fallback: manual entry always works

#### Voice & Local AI (completely unique for a journal)
- [ ] Hotkey → record → Whisper transcribes → journal entry saved
- [ ] Voice commands: "Show today's P&L", "Open last trade", "What's my win rate this month?"
- [ ] AI trade debrief (via Ollama) — after trade close, reviews entry/exit/screenshots, gives honest feedback
- [ ] AI auto-tagging — suggests tags based on trade behaviour ("early exit", "fomo", "good setup")
- [ ] AI daily summary — "You traded NQ and ES today. Win rate 60%. Your best setup was X."

#### Storage & Deployment
- [ ] SQLite — zero setup, single file, portable
- [ ] Local web UI (FastAPI + React) — runs on http://localhost, no internet needed
- [ ] Single-file distribution — or minimal install (Python + pip)

### What We Deliberately Skip (V1)

| Feature | Why Not |
|---------|---------|
| Options greeks/flow | Niche, complex. Futures + stocks first |
| Prop firm compliance tracking | Complex, only relevant to eval traders |
| Real-time stock screener | Needs server infrastructure |
| Simulator/backtester | Whole separate product, not a journal |
| 600+ stats | Overwhelming, most unused. 20-30 > 600 |
| Dividend tracking | Nice-to-have, not core |
| Multi-account | Add later if needed |
| Social/sharing | Privacy-first means no sharing |
| Cloud sync | Deliberate — local-first. Optional later |

### Why A Trader Would Choose This Over TradesViz

*"I can press a hotkey to screenshot my NQ chart the moment I enter, speak my trade notes while I'm still in the trade, and when I close it the AI debrief tells me what I did right and wrong. All local, all free, no monthly fee, my data never leaves my PC."*

That's a product TradesViz literally cannot offer at any price.
